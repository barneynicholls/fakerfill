FakerFill

Fill forms with fake data. Detection is automatic; rules let you pin exact values for particular fields.

Chrome and Edge only allow shortcuts to be changed from their own settings page. You can also assign a key to “Fill only the form containing the focused field” there.

Behaviour

Field rules

Rules are checked top to bottom before automatic detection; the first match wins. A rule matches a field's name, id, label, placeholder, aria-label or autocomplete. Values can mix fixed text with generator tokens such as {{email}} or {{number:1-10}}. For selects, use the option value or text (separate several with | for multi-selects); for checkboxes, true or false. Tip: right-click any field on a page and choose Create FakerFill rule for this field…

Generator tokens

Click a token to copy it. Values within one fill are consistent: {{email}} is built from {{firstName}} and {{lastName}}, and every password field gets the same {{password}}.
